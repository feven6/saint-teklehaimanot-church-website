# Saint Teklehaimanot Church Website

A responsive multi-page community website built with HTML, CSS, and JavaScript.

## Features
- Responsive navigation for desktop and mobile
- Home, About, Services, Events, and Contact pages
- Functional demo sign-up/sign-in using browser localStorage
- Contact, directions, social links, and donation information
- Accessible modal interactions and responsive layout

## Run locally
Open `indx.html` in a browser, or use a local development server such as VS Code Live Server.

> The sign-in system is a front-end demo only. Production authentication and online donations require a secure backend/payment provider.
